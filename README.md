One line that gets you out of work and gets a laugh: my bedroom has gone on strike.

> My bed has officially gone on strike, my alarm clock joined the picket line, and my coffee maker filed a complaint -- I need today to negotiate with my own bedroom.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: one line, 1 to 200 characters.

```sh
python3 main.py
```
